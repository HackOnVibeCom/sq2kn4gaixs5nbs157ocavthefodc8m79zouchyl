# Five-minute demo video script — Try First

Use the live Netlify URL. Before recording, clear the demo browser’s local storage if you want a clean counter view. Alternatively, use **Seed demo data** and explicitly call the examples seeded demo data. Never present those samples as real users or adoption metrics.

| Time | On screen and narration |
|---|---|
| 0:00–0:30 | Show the home screen. “When a gadget catches your eye, the easiest thing is to buy it now. Try First gives you a better next step: borrow a similar item, wait, and decide.” |
| 0:30–1:05 | Point out the item and price fields, the 48-hour default, and the visible 45-second Demo mode. “There’s no signup and no payment data. For this demo I’ll use the short timer.” |
| 1:05–1:40 | Select **Seed demo data**. Show the ready-to-decide card and the already-skipped example. “These are seeded examples so judges can test the decision flow without waiting.” |
| 1:40–2:15 | On the ready card choose **Skip · save it**, then **Share saved result**. Show the generated PNG. “A skipped purchase becomes a compact result people can share.” |
| 2:15–3:05 | Start a fresh demo buffer for a gadget and choose **Ask a friend to lend it**. Open the copied buddy URL in another browser or device. “The invite asks for practical help: can my friend lend me one to try?” |
| 3:05–3:45 | On the buddy card choose **I can lend one to try** or the nudge option. Show the share sheet or copied reply, then the **Put your own purchase on pause** CTA. “The friend can answer in the chat they already use, then start their own buffer.” |
| 3:45–4:25 | Return to the buyer view. Show the countdown or due decision buttons. “The timer state comes from stored timestamps, so a page refresh does not restart it.” |
| 4:25–5:00 | Open **Stats** and read the displayed values exactly as they appear. “These counters are local to this browser, not cross-device analytics; seeded data is only for this demo. The growth loop is the useful lending invite, the friend’s own buffer, and the shareable Skip result.” |

## Recording notes

- If using the seed button, say the cards are synthetic examples. Do not claim they represent users.
- Read the values visible on the **Stats** page; do not insert invented totals or conversion rates.
- “Invites opened” and “invitees who started” are local to the browser recording that action, not a synchronized aggregate.
- The HackOnVibe publisher is disabled for this hackathon; use the Netlify URL for the judge-facing demo.
